# rup.AI.ya

This is the SIMPLEST expense tracker that you or any Indian could ever ask for!

## Setup Steps:

• Uses a GROQ-API for a web assistant
  - GROQ : https://console.groq.com/home

• Clone the project and create a `.env` file in your root directory and paste them with these names:
  - `VITE_GROQ_API_KEY`

• `npm install`

• `npm run dev`

And your savings go boom! 💥

## PLEASE NOTE:
• Sign-up and login are stored in this browser. Accounts are not shared across devices, and clearing site data removes them. Passwords are hashed before they are saved; anyone with access to the browser can still read the account list.
